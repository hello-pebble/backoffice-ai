# 릴리스 노트는 사용자 영향과 운영 확인만 짧게 기록한다.

## 작성 형식

```markdown
## vX.Y.Z — YYYY-MM-DD

| 구분 | 내용 |
|---|---|
| 추가 | 사용자에게 새로 제공된 기능 |
| 변경 | 달라진 동작 또는 화면 |
| 수정 | 해결한 오류 |
| 운영 | 배포·환경 변수·데이터 관련 확인 사항 |

배포 확인: Vercel / API / 워커
롤백 기준: <!-- 문제가 생기면 이전 버전으로 되돌릴 조건 -->
```

## 예시

## v0.2.0 — 2026-08-22

| 구분 | 내용 |
|---|---|
| 추가 | 콘텐츠 스튜디오와 AI 운영 센터 추가 |
| 변경 | 업무 상태를 제목 왼쪽에 표시 |
| 수정 | 모달 닫기 버튼 동작 수정 |
| 운영 | 로컬 AI 모델은 테스트 용도로만 사용 |

배포 확인: Vercel / API / 워커
롤백 기준: 콘텐츠 패키지 생성 오류가 반복되면 v0.1.x로 복원

상세 배포 절차: [브랜치 및 배포 전략](BRANCH_STRATEGY.md)
