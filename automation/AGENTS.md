# 자동화는 검토 가능한 결과를 만들고, 외부 발행은 명시적 승인 뒤에만 실행한다.

| 항목 | 규칙 | 결과값 |
|---|---|---|
| 소유 범위 | `automation/`의 작업 로직을 수정한다. | 자동화 기능 변경 |
| 공유 코드 | `shared/`에는 화면이나 특정 업무에 종속되지 않는 재사용 가능한 유틸리티만 둔다. | 낮은 결합도 |
| 실행 안전성 | 기본 실행은 생성·검토 대기까지만 처리한다. | 자동 발행 방지 |
| 전달 방식 | 결과와 상태는 API·DB·객체 저장소로 전달한다. | 화면에서 확인 가능한 결과 |
| 재시도 | 같은 요청을 다시 실행해도 중복 발행되지 않게 한다. | 멱등성 있는 작업 |
| 오류 | 실패 원인·재시도 가능 여부·실행 시간을 남긴다. | 운영 가능한 실행 이력 |
| 검증 | 실제 계정 발행 없이 안전한 입력으로 확인한다. | 자동화 검증 결과 |
