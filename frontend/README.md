# Frontend

정적 파일로만 구성된 화면입니다. 빌드 도구나 프레임워크 없이 순수 HTML/CSS/JS로 작성되어 있고, 모든 API는 `backend/`(Kotlin) 서버가 제공합니다. 이 폴더에는 비밀값이나 업무 규칙을 두지 않습니다.

## 구성

- `static/index.html`: 대시보드 화면 뼈대. 로그인 게이트(Google 로그인 + 데모로 둘러보기), 데모 배너, 사이드바 내비게이션(AI 운영 센터 · 주제 대본 초안 · 콘텐츠 생성 에이전트 · 메일 · 최신 소식 · 국내 관심 종목 · Slack 연결 · 인스타툰 대본)
- `static/app.js`: 화면 로직 전체. `/api/*`를 호출해 데이터를 그려주는 순수 함수 위주(빌드 없이 바로 브라우저에서 실행)
  - 세션은 HttpOnly 쿠키로 관리하고, 로그인 여부만 표시용 쿠키(`office_session_hint`)로 즉시 판단해 로그인 카드 깜빡임을 방지
  - `load()`는 응답을 모아 기다리지 않고 **도착하는 대로** 그린다. 외부 API를 부르는 `/api/dashboard`가 늦어도 나머지 화면이 먼저 뜬다
  - `renderPaged`가 목록형 UI(뉴스, AI 운영 이력, 콘텐츠 패키지, 주제 대본, 인스타툰)의 페이지네이션을 공통 처리
  - AI 운영 센터는 서버가 준 실행 목록을 받아 **기능·모델·기간 필터와 모델별 집계를 화면에서** 계산한다(타일·표·목록이 같은 배열에서 나와 어긋나지 않는다)
  - 컷 이미지는 생성 요청 뒤 `생성중`이 남아 있는 동안만 3초 폴링하고, 끝나면 스스로 멈춘다. 이미지 바이트는 목록 응답에 없고 `<img>`가 `/api/toon-images/{id}`로 따로 가져온다
  - 사이드바는 스크롤 위치를 따라 현재 섹션을 표시한다
- `static/styles.css`: 스타일시트 (서체는 IBM Plex Sans KR, Google Fonts에서 로드)
- `static/favicon.svg`: 파비콘
- `static/vercel.json`: 정적 배포 설정

## 디자인

운영 콘솔 성격으로 잡았습니다. 서체는 IBM Plex Sans KR 하나, 신호색은 코발트(`--signal`) 하나이고 상태 태그와 현재 위치에만 씁니다.
카드는 그림자 없이 1px 괘선의 평면 한 겹이고, PC에서는 2열 그리드(AI 운영 센터만 전체 폭)에 카드 높이를 고정해
넘치는 내용은 카드 안에서 스크롤합니다. 카드 내부 반응형은 뷰포트가 아니라 **컨테이너 쿼리**로 카드 폭에 맞춰 접힙니다.

## 데모 모드

`body.demo`일 때만 보이는 안내 문구(`.demo-note`)를 마크업에 늘 두고, 개인 계정이 필요한 버튼(Slack 연결, 워커 실행)은 CSS로 감춥니다.
데모 여부는 `/api/auth/me` 응답의 `demo` 필드로 판단합니다.

## 규칙 (AGENTS.md)

- API 응답을 표시만 하고, API 계약 변경은 backend 담당과 먼저 맞춘다.
- 로딩·빈 상태·실패 상태를 모두 사용자 문구로 표시한다.
- API 키, OAuth 토큰, DB 접속 정보를 넣지 않는다.
