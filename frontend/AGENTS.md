# 화면은 API 계약을 소비하고, 비밀값·업무 규칙을 직접 갖지 않는다.

| 항목 | 규칙 | 결과값 |
|---|---|---|
| 소유 범위 | `frontend/`와 정적 화면 파일만 수정한다. | 화면 변경 PR |
| API | `/api` 응답을 표시하고, API 계약 변경은 먼저 backend 담당과 맞춘다. | 호환되는 화면 |
| 상태 | 로딩·빈 상태·실패 상태를 모두 사용자 문구로 표시한다. | 이해 가능한 UX |
| 보안 | API 키, OAuth token, DB 접속 정보는 넣지 않는다. | 브라우저 비밀값 0개 |
| 검증 | 데스크톱·모바일과 주요 사용자 흐름을 확인한다. | 화면 확인 결과 |
