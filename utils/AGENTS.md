# 공용 유틸리티는 특정 화면·업무에 종속되지 않고, 재사용 가능한 기능만 제공한다.

| 항목 | 규칙 | 결과값 |
|---|---|---|
| 소유 범위 | `utils/`의 공통 데이터·로그·보조 기능만 수정한다. | 재사용 가능한 유틸리티 |
| 의존성 | `frontend/`나 특정 에이전트에 직접 의존하지 않는다. | 낮은 결합도 |
| 오류 처리 | 민감 정보를 로그에 남기지 않고, 원인을 호출자에게 전달한다. | 안전한 오류 처리 |
| 변경 영향 | 공개 함수 변경 시 호출하는 모듈을 함께 확인한다. | 호환되는 공통 기능 |
