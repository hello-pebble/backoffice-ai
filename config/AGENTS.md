# 설정에는 구조와 예제만 저장하고, 실제 비밀값과 개인 계정 정보는 저장소에 넣지 않는다.

| 항목 | 규칙 | 결과값 |
|---|---|---|
| 소유 범위 | 설정 예제와 기본값만 수정한다. | 재현 가능한 설정 안내 |
| 비밀값 | API 키·비밀번호·OAuth token은 `*.example`에도 넣지 않는다. | 비밀값 없는 저장소 |
| 환경 분리 | 개발·스테이징·운영 값은 환경 변수 또는 배포 비밀 설정으로 나눈다. | 안전한 배포 설정 |
| 변경 기록 | 새 환경 변수는 용도와 필요한 배포 대상을 문서화한다. | 누락 없는 배포 준비 |
